# MailInsider — Enterprise Product Film Storyboard

**Duration:** ~80 seconds · **Format:** 1920×1080 · **Source:** live product UI + cinematic title cards  
**Audience:** founders, AEs, and operators who send cold outreach through Gmail  
**Demo account:** `demo@mailinsider.app` (non-production sample data only)

## Narrative arc

| Beat | Time | Visual | Idea |
|------|------|--------|------|
| Hook | 0–7s | Dark cinematic card | You send. Then you guess. |
| Problem | 7–16s | Fragmented cards: Sent / Sheet / Inbox | Opens, clicks, and replies live in different places. |
| Reveal | 16–26s | Push-in to real MailInsider login → Sent | One client for send, signal, and conversation. |
| Workflow A | 26–38s | Sent list, engagement chips | Sent becomes the system of record. |
| Workflow B | 38–50s | Message detail timeline | Opens, links, documents — labeled honestly. |
| Workflow C | 50–68s | Compose → send → thread reply | Write, send through Gmail, reply in the same thread. |
| Close | 68–80s | Brand lockup + CTA | Send with clarity. |

## Camera language

- Establish full UI before every zoom.
- Slow ease into the interactive element (1.1×–1.35×).
- Hold long enough for the action to read.
- Pull back to re-establish context before the next cut.
- Letterbox + lower-third captions for film framing.

## Audio

- Professional female neural voiceover (en-US Jenny).
- Soft original ambient bed under −22 dB.
- Soft whoosh on scene transitions (optional, subtle).

## Honest capabilities shown

Gmail connect (demo), Sent folder, engagement tags, open/link/document timeline, compose + send, inline reply, follow-up cadence, integrations — only features present in the product.
